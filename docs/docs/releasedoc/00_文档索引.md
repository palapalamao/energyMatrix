## 使用说明

- **01 / 02 / 07 为 .pptd 格式**：在 Kimi 幻灯片编辑器中打开可在线编辑，并可一键导出为标准 PPTX。01、02 已完成校验与逐页渲染目检（预览拼图在各目录 `shots/overview.png`）。
- **03 为 PDF**：通讯稿成品，可直接外发。
- **04 为 XLSX**：典型面积配置已通过公式与汇总行校验。
- **05 / 06 / 08 为 DOCX**：通过 OOXML 结构校验；本机无 LibreOffice，未做逐页渲染目检（05 有 1 个 TOC 样式回退警告，不影响正文内容）。
- **09 / 10 为厂商硬件规格书**：F200 边缘引擎（3000 点）与 NEXIO 边缘控制器（5000 点），为平台通用件，两份资料原样复用。
- `_extract/` 为中间产物目录：原 V1.0 资料的提取文本、各文档的生成脚本（可复现/可改后再生成）、QA 截图。不需要时可整目录删除，不影响正式交付物。

## 关键产品事实（文档口径统一来源）

- 13 个业务屏：能源总览 / 实时监测与告警 / 工单 / 分项计量树 / 能耗分析 / 定额与对标 / 节能诊断与核证 / 碳排与双碳目标 / 数据模型配置 / 表具与采集器 / 多项目总览 / 报表与关账 / 移动端速览
- 80+ Axon 开放函数；Haystack 4 语义建模，Xeto 规格只读校验
- 三层点位体系 L1 raw → L2 delta → L3 index；EmLedgerEntry 台账为唯一桥梁
- 缺口率 5% 数据质量闸门；折标煤仅统计电/天然气/柴油/蒸汽/热力，水不折标
- Scope 1/2/3 碳核算，绿证注销（emRetired）才计入抵消，排放因子版本化且必填来源
- 节能核证遵循 ASHRAE Guideline 14 / IPMVP Option C
- 边缘硬件：F200（3000 点）/ NEXIO（5000 点，四核 A72 / 4GB / 16GB）
